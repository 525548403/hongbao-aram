红包乱斗 —— 使用说明
====================================

本程序是一个【独立可执行文件】，无需安装 Python，双击即可运行。

【如何运行】
1. 直接双击 "aram_score.exe"；
   —— 或在开始菜单 / 桌面找到 "ARAM Score" 快捷方式双击。
2. 程序会自动在默认浏览器打开评分面板
   （地址：http://127.0.0.1:8777 ）。
3. 程序运行时会出现一个黑色命令行窗口，
   那是它的"控制面板"，【关闭该窗口即可退出程序】。

【拉取真实国服战绩（推荐）】
- 请确保本机已登录英雄联盟客户端；
- 国服跨网读取建议开启加速器；
- 在页面点「拉取战绩」并填写场次（默认 20），
  即可看到最近 N 场大乱斗的雷达图 + S~D 评级。
- 系统会自动识别"我"的账号并高亮。

【只看效果 / 没开客户端】
- 点页面上的「示例数据」即可预览完整界面与评分逻辑，
  无需登录客户端。

【核心机制：为什么能防刷KDA】
传统 WeGame 式评分以 KDA 为主权重，部分玩家靠"躲在后方只混助攻、
不参团、不承伤"刷出虚高评分。本系统：
  1) 用"同队相对贡献占比"替代绝对 KDA —— 队内横向比较，防止躺赢；
  2) 引入"实质贡献指数"检测摸鱼：高 KDA 但低贡献者被惩罚；
  3) 每英雄专属画像：内置 60+ 英雄的"贡献倾向"数据(技能偏向
     伤害 / 承伤 / 治疗护盾控制 / 推塔推进)，据此为每个英雄生成
     专属评分权重 —— 英雄擅长什么，就在哪个维度给分。
     例: Soraka 效用权重≈0.50 / Ashe 伤害权重≈0.39 /
         Leona 承伤权重≈0.31 / Karma 伤害效用双修(无红利可钻)。
     未收录英雄按角色模板 + 实际数据特征自动兜底归类。
  4) 页面展示: 定位标签 + 打法倾向(如"承伤+效用") + 综合游戏分
     (85% 场均评分 + 15% 胜率加成)。
防刷规则（按各英雄画像的主导维度判定）：
  - 高KDA低贡献(疑似保KDA)     → 评分 ×0.70
  - 参战率过低(<35%)           → 评分 ×0.85
  - 主导维度缺失(全程划水)     → 评分 ×0.80
评级：S≥85 / A≥70 / B≥55 / C≥40 / D<40

【🧧 红包局（组队惩罚玩法）】
组队全自动识别，无需手动填写 —— 拉取战绩后，程序统计每场
队友的出现频率：固定开黑好友几乎每场都在，而纯路人在大乱斗
数千人玩家池里几乎不可能重复匹配到。
说明: Riot 新版战绩接口的单场数据里【没有组队标记】(官方已
移除 partyId 字段)，因此"队友出现频率"是从战绩识别开黑的
唯一可靠依据。识别阈值可在左侧面板调整: 宽松25% / 标准40% /
严格60%，标准档适合绝大多数情况。

红包规则（组内名次按"新评分"从高到低排，发红包的是评分最后的）：
  - 组队 3 人 → 组内最后 1 名（第 3 名）发红包
  - 组队 4 人 → 组内最后 2 名（第 3、4 名）发红包
  - 组队 5 人 → 组内最后 2 名（第 4、5 名）发红包
  - 组队 2 人 / 路人局 → 不触发红包
每场比赛的表格会显示「组内#N」标签，需要发红包的玩家整行
红色高亮 + 🧧 标记；比赛标题栏显示组队人数与本场红包人。

【🔥 五杀赏金】
战绩数据自带 pentaKills 字段，程序自动识别每场五杀：
  - 组队成员拿到五杀 → 其余组队队友【每人】给五杀者发一份赏金；
  - 一个五杀触发一次，一场双五杀 = 队友每人发两份；
  - 非组队成员(路人)的五杀不触发；
  - 五杀赏金金额可在左侧悬浮面板调整(默认 ¥20)，改完即时重算。
比赛标题栏显示 "🔥 谁五杀 → 谁谁谁 各付¥N"；表格里五杀者
有金色 🔥 徽章、付赏金者有 🗡 标记。

红包榜（左侧悬浮面板，常驻显示，净结算）：
自动展示组队识别结果（每位成员出现场次）+ 排行榜。每人显示
净额: 负数(红)=应付出(红包惩罚+五杀赏金), 正数(绿)=五杀赏金
收入。红包单价 / 五杀赏金 / 识别阈值均可改，即时重算。

【安装到本机（开始菜单+桌面快捷方式）】
- 右键 "安装.bat" → 以管理员身份运行（普通用户也可，会装到
  %LOCALAPPDATA%\Programs\ARAM-Score）；
- 或双击 "安装.bat" 按提示完成。

【常见问题】
Q: 点「拉取战绩」报错 "找不到 LCU 凭据"？
A: 客户端未登录或未运行。先启动英雄联盟并登录。
Q: 报错 "远程 SGP 失败 / 连接失败"？
A: 国服战绩在腾讯远程服务器，本机需能联网（建议加速器）。
Q: 浏览器没自动打开？
A: 手动访问 http://127.0.0.1:8777 即可。
Q: 想改端口？
A: CMD 里运行 "aram_score.exe 9000" 即用 9000 端口。
