红包乱斗 —— 使用说明
====================================
当前版本：v1.2.0（开发版 / dev）

【v1.2 新增】
  · 桌面常驻版：托盘后台运行，自动检测对局结束并弹窗
  · 弹窗改到屏幕左下角，不抢游戏焦点，15 秒倒计时自动消失
  · 修复对局结束检测不到（EndOfGame 阶段拿不到对局号）
  · 界面改为「展示模式 + 单一更新按钮」：战绩总览 / 从现在开始统计
  · 新增「往前一场 / 往后一场」自定义微调统计范围
  · 桌面版检测到对局结束后，已打开的网页面板自动刷新最新战绩


【两个版本怎么选】
  aram_score_desktop.exe   桌面常驻版（推荐）
      托盘常驻 + 自动弹窗 + 网页自动刷新。功能最全。
  aram_score.exe           纯网页版
      双击只开浏览器面板，无托盘常驻、不自动弹窗。


【如何运行】
1. 直接双击 "aram_score_desktop.exe"；
   —— 或在开始菜单 / 桌面找到 "ARAM Score" 快捷方式双击。
2. 【重要】先启动并登录英雄联盟客户端（国服建议开加速器），
   否则无法读取战绩。
3. 程序会常驻系统托盘（图标可能需要展开托盘箭头才能看到），
   并自动在浏览器打开战绩面板（http://127.0.0.1:8777）。
4. 正常打游戏即可 —— 每局结束后左下角自动弹出本场战绩，
   网页面板也会自动刷新，不需要再手动点任何按钮。


【网页面板怎么用】
· 展示模式（分段控件，切换即生效）：
    战绩总览—— 按「场次」拉最近 N 场，全部纳入统计，适合看整体画像
    从现在开始统计 —— 只统计从某个时间点之后打的局，适合长期记账
· 更新：打完一局后永远只点「🔄 更新最新战绩」这一个按钮。
    总览模式 → 按场次重拉最近 N 场重算整体
    记账模式 → 只把上次之后新打的那场追加进来
  桌面版检测到对局结束时，网页会自动完成刷新，无需手点。
· 往前一场 / 往后一场：在已加载范围内 ±1 场微调统计范围（不重新联网）


【核心机制：为什么能防刷KDA】
传统 WeGame 式评分以 KDA 为主权重，部分玩家靠"躲在后方只混助攻、
不参团、不承伤"刷出虚高评分。本系统：
  1) 用"同队相对贡献占比"替代绝对 KDA —— 队内横向比较，防止躺赢；
  2) 引入"实质贡献指数"检测摸鱼：高 KDA 但低贡献者被惩罚；
  3) 每英雄专属画像：内置 60+ 英雄的"贡献倾向"数据(技能偏向
     伤害 / 承伤 / 治疗护盾控制 / 推塔推进)，据此为每个英雄生成
     专属评分权重 —— 英雄擅长什么，就在哪个维度给分。
     例: Soraka 效用权重≈0.50 / Ashe 伤害权重≈0.39 /
         Leona 承伤权重≈0.31 / Karma 伤害效用双修(无红利可钻)。
     未收录英雄按角色模板 + 实际数据特征自动兜底归类。
  4) 页面展示: 定位标签 + 打法倾向(如"承伤+效用") + 综合游戏分
     (85% 场均评分 + 15% 胜率加成)。
防刷规则（按各英雄画像的主导维度判定）：
  - 高KDA低贡献(疑似保KDA)     → 评分 ×0.70
  - 参战率过低(<35%)           → 评分 ×0.85
  - 主导维度缺失(全程划水)     → 评分 ×0.80
评级：S≥85 / A≥70 / B≥55 / C≥40 / D<40
雷达六轴：伤害% / 承伤% / 辅助%(有效治疗+给队友的盾) / 控制%(控场时间)
          / 参战% / 推进%（均为占全队比例）


【🧧 红包局（组队惩罚玩法）】
组队全自动识别，无需手动填写 —— 拉取战绩后，程序统计每场
队友的出现频率：固定开黑好友几乎每场都在，而纯路人在大乱斗
数千人玩家池里几乎不可能重复匹配到。
说明: Riot 新版战绩接口的单场数据里【没有组队标记】(官方已
移除 partyId 字段)，因此"队友出现频率"是从战绩识别开黑的
唯一可靠依据。识别阈值可在左侧面板调整，手动增删会被持久记住。

红包规则（组内名次按"新评分"从高到低排，发红包的是评分最后的）：
  - 组队 3 人 → 组内最后 1 名（第 3 名）发红包
  - 组队 4 人 → 组内最后 2 名（第 3、4 名）发红包
  - 组队 5 人 → 组内最后 2 名（第 4、5 名）发红包
  - 组队 2 人 / 路人局 → 不触发红包
红包由组内前 1、2 名拆随机金额（收入随机，不计入榜单）。
每场比赛的表格会显示「组内#N」标签，需要发红包的玩家整行
红色高亮 + 🧧 标记；比赛标题栏显示组队人数与本场红包人。

【🔥 五杀赏金】
战绩数据自带 pentaKills 字段，程序自动识别每场五杀：
  - 组队成员拿到五杀 → 其余组队队友【每人】给五杀者发一份赏金；
  - 一个五杀触发一次，一场双五杀 = 队友每人发两份；
  - 非组队成员(路人)的五杀不触发；
  - 五杀赏金金额可在左侧悬浮面板调整(默认 ¥20)，改完即时重算。
比赛标题栏显示 "🔥 谁五杀 → 谁谁谁 各付¥N"；表格里五杀者
有金色 🔥 徽章、付赏金者有 🗡 标记。

红包榜（左侧悬浮面板，常驻显示，净结算）：
自动展示组队识别结果（每位成员出现场次）+ 排行榜。每人显示
净额: 负数(红)=应付出(红包惩罚+五杀赏金), 正数(绿)=五杀赏金
收入。红包单价 / 五杀赏金 / 识别阈值均可改，即时重算。


【安装到本机（开始菜单+桌面快捷方式）】
- 右键 "安装.bat" → 以管理员身份运行（普通用户也可，会装到
  %LOCALAPPDATA%\Programs\ARAM Score）；
- 或双击 "安装.bat" 按提示完成。


【常见问题】
Q: 点更新报错 "找不到 LCU 凭据"？
A: 客户端未登录或未运行。先启动英雄联盟并登录。
Q: 报错 "远程 SGP 失败 / 连接失败"？
A: 国服战绩在腾讯远程服务器，本机需能联网（建议加速器）。
Q: 打完一局没弹窗？
A: ① 确认托盘程序在运行（图标在托盘右下角可能需展开）；
   ② 国服 SGP 数据有延迟，程序会重试最多 120 秒；
   ③ 若弹出提示"远程战绩暂未就绪"，稍后在网页点
      「🔄 更新最新战绩」补录该场。
Q: 弹窗会挡住游戏吗？
A: 不会。浮窗在屏幕左下角，且不抢游戏焦点，15 秒后自动消失。
Q: 浏览器没自动打开？
A: 手动访问 http://127.0.0.1:8777 即可。
Q: 想改端口？
A: CMD 里运行 "aram_score.exe 9000" 即用 9000 端口。
Q: 旧版程序还在后台占端口？
A: 托盘图标右键"退出"彻底关闭；或任务管理器结束
   aram_score_desktop.exe / aram_score.exe 再启动新版。
Q: 数据存在哪？会丢吗？
A: aram_matches.json（战绩库）与 aram_settings.json（设置）
   保存在 exe 同目录，卸载前备份即可。
