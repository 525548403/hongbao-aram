## 这是什么

一个跑在Windows 上的**独立可执行文件**，专门解决大乱斗里的两个痛点：

1. **刷KDA** —— 躲在后排混助攻、不参团不承伤，也能打出漂亮 KDA 拿 MVP 评价。
   本工具用「同队相对贡献占比」替代绝对 KDA，让你和队友的真实贡献一目了然。
2. **开黑红包** —— 群里开黑谁发红包、谁摸鱼了算错。本工具自动识别固定队友、
   按组内新评分排名，该发红包的人一目了然，还能算五杀赏金和净结算榜单。

**v1.2 起新增**：程序常驻系统托盘后台运行，**自动检测对局结束**并弹出左下角
轻量浮窗（不抢游戏焦点、15 秒自动消失），同时网页面板自动刷新最新战绩 ——
你不需要再手动点任何按钮。

## 快速开始

### 桌面版（推荐，功能最全）

1. 下载发行版里的安装包 **`红包乱斗-安装包-v1.3.0.exe`**
2. 双击安装（**无需管理员权限**，装到 `%LOCALAPPDATA%\Programs\ARAM Score`）
3. 桌面/开始菜单双击「红包乱斗」启动
4. **先启动并登录英雄联盟客户端**（国服建议开加速器）
5. 程序会常驻托盘，并自动打开网页面板 `http://127.0.0.1:8777`

之后你正常打游戏就行 —— 对局一结束就自动弹窗 + 网页自动更新。

| 缺陷 | 说明 |
|---|---|
| LCU gameflow 不可用 | `lockfile` 指向的是 **Riot Client** 端口，**不提供 `lol-*` 接口**（实测全部 404）。真正的 LeagueClient API 在另一端口且其 lockfile 是空文件。检测改用**战绩轮询**（LeagueAkari 思路） |
| DETAILS 拉不到数据 | 路径应为 `HN10_<gameId>`（**不带 `TENCENT_` 前缀**），且返回的是精简结构（participants 只剩 puuid）。改为**从 SUMMARY 取 participants**（含完整统计） |
| `queueId` 缺失 | 腾讯 SGP 的 `queueId` 在对局节点上，participants 里没有，导致被误判「非大乱斗」而静默跳过。已自动补齐 |

## 核心机制：为什么能防刷 KDA

传统 WeGame 式评分以 KDA 为主权重，部分玩家靠"躲在后方只混助攻"刷出虚高评分。本系统：

1. **同队相对贡献占比**替代绝对 KDA —— 队内横向比较，防止躺赢
2. **实质贡献指数**检测摸鱼 —— 高 KDA 但低贡献者被惩罚
3. **每英雄专属画像** —— 内置 60+ 英雄的"贡献倾向"数据（技能偏向伤害/ 承伤 /
   治疗护盾控制 / 推塔推进），据此为每个英雄生成专属评分权重：
   英雄擅长什么，就在哪个维度给分。
   - Soraka 效用权重 ≈ 0.50｜Ashe 伤害权重 ≈ 0.39
   - Leona 承伤权重 ≈ 0.31｜Karma 伤害效用双修（无红利可钻）
   - 未收录英雄按角色模板 + 实际数据特征自动兜底归类
4. **页面展示** —— 定位标签 + 打法倾向（如"承伤+效用"）+ 综合游戏分
   （85% 场均评分 + 15% 胜率加成）

**防刷规则**（按各英雄画像的主导维度判定）：

| 情形 | 惩罚 |
|---|---|
| 高 KDA 低贡献（疑似保 KDA） | 评分 ×0.70 |
| 参战率过低（<35%） | 评分 ×0.85 |
| 主导维度缺失（全程划水） | 评分 ×0.80 |

**评级**：S ≥ 85｜A ≥ 70｜B ≥ 55｜C ≥ 40｜D < 40

**雷达六轴**（均为占全队比例，网格上限随本局最大值自适应）：
伤害% / 承伤% / 辅助%（有效治疗+给队友的盾）/ 控制%（控场时间）/ 参战% / 推进%

## 🧧 红包局（组队惩罚玩法）

### 组队全自动识别

Riot 新版战绩接口的单场数据里**没有组队标记**（官方已移除 `partyId` 字段），
因此"队友出现频率"是从战绩识别开黑的唯一可靠依据：
固定开黑好友几乎每场都在，而纯路人在大乱斗数千人玩家池里几乎不可能重复匹配到。

识别阈值可在左侧面板调整（宽松 / 标准 / 严格），名单支持手动 ✕ 删除与 ＋ 添加，
手动增删会被持久记住。

### 红包规则（组内名次按"新评分"从高到低排）

| 组队人数 | 谁发红包 |
|---|---|
| 3 人 | 组内最后 1 名（第 3 名） |
| 4 人 | 组内最后 2 名（第 3、4 名） |
| 5 人 | 组内最后 2 名（第 4、5 名） |
| 2 人 / 路人局 | 不触发 |

红包由组内前 1、2 名拆随机金额（收入随机，不计入榜单，避免"薅羊毛"）。

### 🔥 五杀赏金

战绩数据自带 `pentaKills` 字段，程序自动识别每场五杀：

- 组队成员拿到五杀 → 其余组队队友**每人**给五杀者发一份赏金
- 一个五杀触发一次，一场双五杀 = 队友每人发两份
- 非组队成员（路人）的五杀不触发
- 赏金金额可调（默认 ¥20），改完即时重算

### 红包榜（左侧悬浮面板，常驻）

只显示组队成员，每人显示**净额**：
负数（红）= 应付出（红包惩罚 + 五杀赏金），正数（绿）= 五杀赏金收入。

## 网页面板操作

### 两种展示模式

| 模式 | 口径 | 场次输入 |
|---|---|---|
| **战绩总览** | 按场次拉最近 N 场，全部纳入统计 | 生效 |
| **从现在开始统计** | 只统计锚定之后的对局，之后每次更新只追加新打的那场 | 置灰 |

切换模式会**立即按新口径刷新一次**。

### 只有一个动作按钮

打完一局后**不用判断该点哪个**，永远只点 **「🔄 更新最新战绩」**：

- 总览模式 → 按场次重拉最近 N 场，重算整体
- 记账模式 → 只把上次之后新打的那场追加进来

桌面版检测到对局结束时，已打开的网页会**自动完成上述刷新**，无需手点。

### 往前 / 往后一场

在已加载的范围内 ±1 场微调统计范围（不重新联网，瞬时响应）。

## 常见问题

**Q：点更新报错「找不到 LCU 凭据」？**
A：英雄联盟客户端未运行或未登录。先启动并登录客户端。

**Q：报错「远程 SGP 失败 / 连接失败」？**
A：国服战绩在腾讯远程服务器，本机需能联网，建议开加速器。

**Q：打完一局没弹窗？**
A：① 确认托盘程序在运行（图标在托盘右下角可能需展开）；
② 国服 SGP 数据有延迟，程序会重试最多 120 秒；
③ 若弹出提示「远程战绩暂未就绪」，稍后在网页点「🔄 更新最新战绩」补录。

**Q：弹窗会不会挡住游戏 / 打断操作？**
A：不会。浮窗在**左下角**，且不抢焦点（`WA_ShowWithoutActivating`），
游戏中不会被切走焦点，15 秒后自动消失。

**Q：浏览器没自动打开？**
A：手动访问 `http://127.0.0.1:8777` 即可。

**Q：想改端口？**
A：CMD 里运行 `aram_score.exe 9000` 即用 9000 端口。

**Q：旧版程序还在后台占端口？**
A：托盘图标右键「退出」彻底关闭；或任务管理器结束
`aram_score_desktop.exe` / `aram_score.exe` 再启动新版。

**Q：数据存在哪？会不会丢？**
A：`aram_matches.json`（战绩库）与 `aram_settings.json`（设置）保存在 exe 同目录，
卸载前备份即可。

## 开发者信息

### 技术链路（国服，逆向自 LeagueAkari）

1. 本地 LCU 客户端 `/entitlements/v1/token` 拿 Riot 签发的 entitlements JWT
2. 解码 JWT 的 `sub` 声明 = 当前账号 puuid
3. 从 LeagueAkari 配置（`lastConnectedClient.rsoPlatformId`）得到区服，
   拼出 SGP 子标识 `TENCENT_<rsoPlatformId>`（如黑色玫瑰 = HN10）
4. 用 Bearer entitlements 令牌请求腾讯 SGP：
   - `.../match-history-query/v1/products/lol/player/<puuid>/SUMMARY` → 对局列表
   - `.../match-history-query/v1/products/lol/TENCENT_HN10_<gameId>/DETAILS` → 单场10 人完整 stats
5. stats 喂入评分内核（`aram_score_system.compute`）输出防刷 KDA 评分 + S~D 评级

### 模块结构

| 文件 | 职责 |
|---|---|
| `aram_score_system.py` | 评分内核（贡献占比/画像权重/防刷规则/评级） |
| `aram_redpacket.py` | 红包局规则（组队标注/发红包/五杀赏金/榜单聚合） |
| `aram_akari_framework.py` | 国服LCU + SGP 抓取框架 |
| `aram_champions.py` | 60+ 英雄画像数据（贡献倾向权重） |
| `aram_web.py` | HTTP 服务 + 算分封装 + 战绩库 + `/api/*` 接口 |
| `index.html` | 前端面板（雷达图/评分表/红包榜/模式切换） |
| `main_desktop.py` | 托盘常驻入口（检测对局结束 → 弹窗 + 广播） |
| `lcu_watcher.py` | 对局结束检测层（游戏进程 + SGP 战绩轮询 + LCU 事件三通道） |
| `match_view.py` | 单场战绩 → 弹窗视图模型（只含我方 5 人，复用 Web 端评分） |
| `result_popup.py` | 左下角轻量浮窗（PySide6，15s 自动消失） |

### 开发运行

```bash
# 依赖（venv 路径按本机实际情况）
pip install pyinstaller requests urllib3 websocket-client PySide6

# 桌面版
python main_desktop.py

# 网页版
python aram_web.py 8777

# 排查「游戏结束不弹窗」——分 5 步自检，指出卡在哪一环
python diagnose_detect.py
```

### 构建安装包

```bash
# 打包桌面版 exe（windowed，无黑框）
pyinstaller --noconfirm --clean aram_desktop.spec
cp dist/aram_score_desktop.exe release/

# 打包网页版 exe
pyinstaller --noconfirm --clean aram_score.spec
cp dist/aram_score.exe release/

# 构建 NSIS 安装包（需先安装 NSIS）
cd release && makensis aram_installer.nsi
```
